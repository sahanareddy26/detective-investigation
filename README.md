# Detective Investigation System

## Team Project

This project is a Java-based console Detective Investigation System.

The system simulates an investigation into a missing examination question paper.

## Features

- View all suspects
- Investigate a suspect
- Collect clues
- View collected clues
- Accuse a suspect
- Check whether the accusation is correct
- Maximum three accusation attempts
- Exit the investigation

## Project Files

### Suspect.java
Manages suspect information.

### ClueManager.java
Stores and manages the five clues.

### Investigation.java
Handles suspect searching, investigation and accusation logic.

### DetectiveGame.java
Contains the main method, menu and integration of all components.
